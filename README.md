# 实时 AI 变声器 v2.0（直播用，C++）

麦克风说话 → 实时变成目标人的声音 → 直播软件直接选用。
**变声端**：C++ 编写；有显卡（Intel / AMD / NVIDIA，DirectML）用显卡，没有显卡自动用 CPU。
**直播接入**：OBS 插件（免驱动），以及自研虚拟麦克风「AI变声器 麦克风」（抖音/快手直播伴侣等任何软件可选）。
**训练端**：在 GPU 服务器上用一段目标人的样本音频生成声音模型。

### v2.0 更新
- **显卡加速**：DirectML 一套代码支持 Intel / AMD / NVIDIA 显卡；显卡初始化失败自动回退 CPU。
- **修复断字/吞字**：噪声门改为平滑门（保持 300ms + 渐隐），不再切掉轻声字头字尾。模拟小音量麦克风实测：断字率 **9%~18.5% → 0%~1.3%**。
- **音高稳定**：短空洞补齐、八度跳变纠错、中值平滑。
- **新界面**：商用风格，简易模式（选声音 → 一键开始）/ 高级模式（全部参数）、首次启动向导、一键性能测试并自动配置。
- **自带输出**：OBS 插件（共享内存，免驱动），虚拟麦克风驱动（当前为测试签名版，见下文）。
- **一键安装包**：`AIVoiceChanger-Setup-2.0.0.exe`。
- CPU 跟不上时自动加大块长，避免断音。

讲话的**语气、情绪、轻重缓急、停顿、笑声、气声**都来自你本人的实时表演，模型只替换音色：

| 保留什么 | 怎么做到的 |
|---|---|
| 说的内容/咬字 | HuBERT(ContentVec) 提取与音色无关的内容特征 |
| 语调、情绪起伏 | RMVPE 逐 10ms 提取你的真实音高曲线，原样（或整体变调后）驱动合成 |
| 音量/轻重/语气强弱 | 输出音量包络跟随你的原声（"音量跟随原声"参数） |
| 呼吸、清辅音 | 清辅音保护：无声段降低音色检索强度，避免吐字发糊 |
| 目标音色 | RVC v2 声码器（NSF-HiFiGAN）+ 训练集特征检索库 |

## 一、训练声音模型（GPU 服务器）

当前已部署在 V100 服务器 `/root/vcx`（venv、RVC 训练代码、预训练底模都已装好）。

### 1. 准备样本音频
- **干声**：只有人声，无背景音乐、无混响、无多人说话。
- **时长**：至少 1~2 分钟能用；**10~30 分钟效果最好**。
- **覆盖面**：尽量包含平静、开心、激动、轻声、大声、提问、笑等多种语气。模型学到的音域越宽，你实时表演时就越不容易失真。
- 格式不限：wav / flac / mp3 / m4a…；可以是一个文件，也可以是一个文件夹。

### 2. 训练
```bash
cd /root/vcx
venv/bin/python train_voice.py --name 我的声音 --input /path/样本文件夹 --gpu 4
```
常用参数：

| 参数 | 说明 |
|---|---|
| `--name` | 声音名（建议英文/数字） |
| `--input` | 样本文件或文件夹，可多个 |
| `--gpu` | 用哪张卡，如 `4`；多卡 `4-5` |
| `--epochs` | 训练轮数，默认按时长自动（<2分钟 600 轮，<10分钟 300 轮…） |
| `--sr` | `40k`(默认) / `48k` |
| `--lite` | 用轻量底模训练：声码器计算量约 1/4，**4 核及以下 CPU 推荐** |
| `--preview 某句话.wav` | 训练完自动生成一段试听 |
| `--skip-train` | 只重新导出（例如中途停止训练后，用最新检查点导出） |

参考耗时：150 秒样本、300 轮，单张 V100 约 14 分钟。

### 3. 拷贝到 PC
训练完成后输出在 `/root/vcx/output/`：
- `output/<声音名>/` → 拷到 PC 的 `dist\voices\<声音名>\`
- `output/common/` → 拷到 `dist\models\common\`（只需拷一次，所有声音共用）

```powershell
scp -P 36793 -r root@8.156.74.164:/root/vcx/output/我的声音 E:\tts\voice_changer\dist\voices\
```

### 轻量底模（`--lite` 需要）
当前服务器上已训练好：`rvc/assets/pretrained_v2/f0G40k_lite.pth`、`f0D40k_lite.pth`（另存了 `*_lite_s14k.pth` 快照）。
重新训练（约 2 张 V100 × 数小时，可随时中断，每 2000 步自动保存，`--resume` 续训）：
```bash
CUDA_VISIBLE_DEVICES=4,5 venv/bin/torchrun --nproc_per_node=2 distill_lite.py --data data --steps 40000 --resume
```
`data/` 下放多人语音（当前用的是 LibriTTS-R dev-clean + AISHELL-3 部分），越多越好。

### 新服务器部署
```bash
mkdir -p /root/vcx && cd /root/vcx
# 把 train_server/ 下所有文件(含 rvc_code.tgz)上传到 /root/vcx 后：
bash setup_env.sh /root/vcx
# 轻量底模从旧服务器拷贝 f0G40k_lite.pth / f0D40k_lite.pth 到 rvc/assets/pretrained_v2/
```
服务器访问 HuggingFace 用的是 hf-mirror.com，且需绕开本机失效的代理（脚本已处理）。

## 二、PC 端使用

### 1. 安装
运行 `AIVoiceChanger-Setup-2.0.0.exe`：
- 检测到 OBS 时可勾选「安装 OBS 插件」；
- 「安装虚拟麦克风」目前是**测试签名版**驱动：会开启 Windows 测试模式（`bcdedit /set testsigning on`），需要重启后再运行开始菜单里的「安装虚拟麦克风 (测试版)」。正式版需要 EV 代码签名证书 + 微软签名（见 `driver/SIGNING.md`），拿到证书前，面向客户建议只用 OBS 插件。
- 界面依赖 Microsoft Edge WebView2 运行时（Win10/11 一般自带）。

### 2. 使用（简易模式）
1. 首次启动向导：选麦克风 → 自动测试显卡/CPU 性能并配置 → 告诉你直播软件里选什么。
2. 点一张**声音卡片**，选 **男声变女声 / 原调 / 女声变男声**，点中间的大按钮开始。`Ctrl+Alt+V` 随时开关。
3. 直播软件：
   - **OBS**：来源 ➕ →「**AI 变声器**」（顶部显示 "OBS 已连接"）；
   - **抖音/快手直播伴侣等**：麦克风选「**AI变声器 麦克风**」（需已安装虚拟麦克风驱动）；
   - 也可在高级模式把"输出到"选成 VB-CABLE 等任意设备。

### 3. 高级模式参数

| 参数 | 默认 | 说明 |
|---|---|---|
| 变调 | 男变女 +8，女变男 -8 | 半音。只整体平移音高，语调起伏保持不变 |
| 音色相似度 | 0.5 | 越大越像目标；实测 0.75 时字错误率 0.20→0.32，不建议超过 0.6 |
| 音量跟随原声 | 0.25 | 越低越跟随你说话的轻重（情绪更真实）|
| 清辅音保护 | 0.33 | 保护 s/sh/c 等气音清晰度，0.5 关闭 |
| 噪声门限 | -60 dB | 平滑门：开门后保持 300ms 再渐隐。环境吵就调高 |
| 推理设备 | 自动 | 显卡（DirectML）或 CPU |
| 块长 / 上下文 | 显卡 200/2000ms，CPU 250/800ms | 块长低于 200ms 时接缝增多，实测字错误率明显上升 |
| 前瞻 | 显卡 60ms，CPU 80ms | 等少量后续语音再输出最新部分，咬字更清楚 |

状态栏"负载"需 < 100%（建议 < 80%）。CPU 模式下连续 3 秒超过 95% 会自动加大块长。

### 4. 命令行工具
```powershell
vc_cli list                                              # 列出麦克风、输出设备、显卡
vc_cli bench --voice voices\digital_human                # ★ 测试本机 CPU 和每块显卡的实时性能
vc_cli convert --voice voices\digital_human --in 录音.wav --out 变声.wav --key 8 [--device 0]
```
`convert` 使用与实时完全相同的流式算法，打印 RTF 和**断字率**。

## 三、性能与音质实测

### v2.0 改动的实测效果（2 核云服务器，CPU，男声 → 女声 +8）
| 版本/设置 | 音色相似度 | 字错误率 CER | 正常音量帧 F0 相关 | 小音量麦克风断字率 |
|---|---|---|---|---|
| v1.0 (噪声门 -50dB 硬切) | 0.974 | 0.215 | 0.994 | 9.0% / 18.5% |
| v2.0 CPU 档 | 0.973 | **0.203** | 0.994 | **0% / 1.3%** |
| v2.0 显卡档参数 (块 200ms/上下文 2000ms) | 0.963 | 0.215 | 0.992 | 0% |

说明：
- 显卡档的速度需要在有独显/核显的电脑上用 `vc_cli bench` 实测；这台云服务器没有 D3D12，无法测。DirectML 回退 CPU 的逻辑已验证。
- 显卡模式下 HuBERT/RMVPE 用 FP16（V100 上校验与 FP32 的信噪比 40.7 / 44.5 dB），编码器/声码器保持 FP32。
- 音色相似度主要取决于训练数据和底模：建议提供 10~30 分钟干声；中文增强底模在单独任务中训练。

### v1.0 数据（参考）

测试机：**2 核 4 线程云服务器 (AMD EPYC 7763)**——比普通台式机弱很多，作为下限参考。
测试内容：男声原声 → 女声 "digital_human"（变调 +8），C++ 流式引擎实时算法。

| 模型 | 块长/上下文 | 每块推理 | RTF (须<1) | 音色相似度 | 字错误率 CER | F0 相关 | 音量相关 |
|---|---|---|---|---|---|---|---|
| (原声, 不变声) | – | – | – | 0.525 | – | – | – |
| 标准版 | 250/800 ms | 447 ms | 1.79 ✗ | 0.974 | 0.215 | 0.993 | 0.989 |
| 标准版 | 400/500 ms | 504 ms | 1.26 ✗ | 0.969 | 0.228 | 0.992 | 0.989 |
| 轻量版 `--lite` | 250/800 ms | 275 ms | 1.10 △ | 0.962 | 0.278 | 0.992 | 0.990 |
| 轻量版 `--lite` | 400/500 ms | 293 ms | 0.73 ✓ | 0.964 | 0.291 | 0.991 | 0.990 |

（轻量版用的是蒸馏 14k 步的底模；底模训练仍在服务器上继续，到 40k 步后用 `--lite` 重新训练声音，清晰度还会再提升。）

- 音色相似度：WavLM 说话人向量与目标样本的余弦相似度（0.525 → 0.97，已基本是目标人）。
- CER：Whisper 识别结果与原声识别结果的差异，越低吐字越清晰。
- F0/音量相关：输出与原声的音高曲线、音量包络的相关系数，接近 1 说明语调、情绪起伏、轻重被完整保留。

**选择建议**
- 6 核及以上的普通台式机/笔记本（i5-10 代 / R5-3600 及以上）：标准版，块长 250ms，负载约 50~70%。
- 4 核及以下或老 CPU：用 `--lite` 训练的声音，块长 300~400ms。
- 以 GUI 状态栏 "负载" 为准：< 80% 即稳定。

## 五、技术细节

**流式推理流程**（每块，CPU 或显卡）：
1. 麦克风 48k → 16k 重采样（多相 Kaiser-sinc）；噪声门只计算增益，作用在输出上（不改送入模型的音频）
2. 滑动窗口（上下文 + 新块）送 HuBERT 得到内容特征；同时并行跑 RMVPE 得到最新一段音高
3. 特征与训练集检索库做 kNN 混合（音色相似度），无声帧降低强度（清辅音保护）
4. 编码器 + Flow（整窗）→ 声码器只解码输出区间（+少量边缘余量）
5. 音量包络跟随原声 → SOLA 相位对齐 + 交叉淡化拼接 → 重采样到声卡采样率

**为避免分块接缝做的处理**：
- 编码器随机噪声、声码器激励噪声按"绝对时间位置"确定性生成，重叠区两次推理一致；
- NSF 正弦激励的初始相位由 C++ 逐帧累积传入，跨块相位连续，没有周期性"咔哒/嗡嗡"；
- 前瞻：HuBERT 对窗口最右边 ~100ms 的特征不可靠（实测余弦相似度仅 0.1~0.6），默认延后 80ms 输出这部分。

**ONNX 导出**：RVC 原版相对位置注意力在 trace 时会把长度固化，已改写为动态形状等价实现，导出后对任意长度与 PyTorch 误差 < 1e-4。
